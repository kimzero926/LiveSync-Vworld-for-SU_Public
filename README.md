# LiveSync-Vworld for SU — 배포판

스케치업 모델을 브이월드 3D 지도 위에 올려 주변 현황과 함께 검토하는 스케치업 확장 프로그램의 버전 정보 저장소입니다.

## 설치 / 업데이트
1. 설치 파일(.rbz)은 개발자에게 직접 받습니다 (업데이트가 필요하면 프로그램 창에 연락처가 표시됩니다).
2. 스케치업 메뉴 **확장 프로그램 › 확장 프로그램 관리자 › 확장 프로그램 설치** 에서 받은 파일을 고릅니다.
3. 스케치업을 다시 시작합니다.
